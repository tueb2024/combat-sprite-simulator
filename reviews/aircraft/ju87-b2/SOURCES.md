# Ju 87 B-2 visual review

- Three-view plan: [Kaboldy, Junkers Ju 87B-2 Stuka](https://commons.wikimedia.org/wiki/File:Junkers_Ju_87B-2_Stuka.svg), CC BY-SA 3.0. `source-plan.svg` is the attributed source; `outline.json` records manually traced top-view coordinates. The game render and review JPGs are adapted from this plan and carry the same CC BY-SA terms.
- Inverted gull wing, fixed faired gear and dimensions: *Fighting Aircraft of the World*, Sharpe and Chant, private Aiphonse copy, PDF page 341 / printed page 337 (B-family proportions); Crosby, *The Complete Guide to Fighters & Bombers of the World*, PDF page 373 / printed page 371. See `assets/aircraft/specs/ju87-b2.json`. No book page is distributed.
- The Blender file and nine bank/propeller frames were generated on the GTX PC. The plotted shape is an arcade-scale interpretation of the plan; the slow dive-bomber behavior is game design.
